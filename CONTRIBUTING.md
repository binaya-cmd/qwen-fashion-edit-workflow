# Contributing
Improve public documentation or contribute a reproducible, cleared public workflow.

Never submit client images, model weights, secrets, confidential prompts, private logs, or proprietary paid workflow details. Keep private working files outside this repository.

Workflow contributions need public sources, exact dependencies, hardware, settings, a sanitized graph, and evidence of a successful run. Label estimates and untested combinations. External licenses and asset permissions remain separate from this repository license.

Ignore rules are not a security boundary: they can be bypassed and do not remove tracked files. Review changes and history using the [publishing checklist](docs/publishing.md).
